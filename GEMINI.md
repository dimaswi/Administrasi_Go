# Workspace Rules & Guidelines

## Aturan Pengeditan File (Wajib Dipatuhi)
1. **Dilarang keras menggunakan script eksternal (Node.js, Python, PowerShell/Bash script, dsb.) untuk mengedit atau memodifikasi file dalam proyek ini.**
2. **Semua pengeditan dan modifikasi kode/file WAJIB dilakukan secara langsung dan manual menggunakan tool editor bawaan (`edit_file` / `write_file`).**
3. **Selalu pastikan hasil perubahan rapi, sesuai standar codebase, dan jaga integritas kode.**
